# yanriabonenko.xyz (sh1dan)

Personal interactive particle card & portfolio page.

## Features
- Interactive Canvas particle system with fluid physics and cursor-chasing dynamics.
- Reactive social links (Telegram, Instagram, Twitch) drawn with particle rendering.
- Soundscapes with ambient loop and interactive sound transitions.
- Interactive Easter egg mode (BigShot Mode) with custom animations and audio.
- Fully responsive across desktop and mobile devices.

## Tech Stack
- HTML5 / Vanilla JavaScript (Canvas API)
- CSS3 animations
- Web Audio API / HTML5 Audio
