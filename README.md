## ✨ Key Features

- 🌌 **Custom Particle Engine**: Fully procedural Canvas 2D particle simulation rendering **SH1DAN** and interactive vector social icons.
- 🧲 **Cursor Wake & Swarm Physics**: Nickname particles respond dynamically to cursor trajectory — getting drawn into the motion wake and swarming after the cursor with elastic damping.
- 🦆 **Interactive Easter Egg ("BigShot Mode")**: 
  - Hovering / holding the rubber duck triggers high-energy background photo transitions, audio stems, and undulating wave dynamics for the nickname.
- 📱 **Full Device Responsiveness**: Dynamic device detection with adapted hitboxes, DPI scaling, and touch-optimized pointer handlers.
- 🔊 **Ambient Audio Experience**: Seamless ambient background soundtrack with instant responsive audio transitions.

## 🚀 Quick Start Locally

Clone the repository and run any local static file server:

```bash
# Clone repository
git clone https://github.com/sh1dan/yanriabonenko.xyz.git

# Enter folder
cd yanriabonenko.xyz

# Run with any static server (e.g. npx serve or Python)
npx serve .
# or:
python -m http.server 8000
```
