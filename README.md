### Overview
- Interactive canvas text particles that react to and follow your cursor
- Social links rendered directly within the particle field
- Ambient audio with interactive tracks
- Easter egg: hover or hold the duck in the top-left corner 🦆

### Running locally
Just open `index.html` in your browser or run:
```bash
npx serve .
```
